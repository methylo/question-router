# 업무 질문 스킬 (question-router)

업무마다 먼저 확인할 것을 묻고, 그 질문 절차로 결과물까지 만드는 스킬입니다. 업무를 다섯 유형 중 하나로 판정하고, 빠진 확인 항목을 되묻고, 유형별 질문 전략으로 결과를 만든 뒤 결과를 만든 질문과 다음 질문을 남깁니다.

## 구성

```text
question-router/
├── SKILL.md                    오케스트레이터: 판정 → 지목·이유 → 전제 확인 → 실행(형식 선택) → 다음 질문
├── README.md                   이 문서
└── references/
    ├── format-profile.md       사용자 공통 형식 기준 — 종결어미·표/산문·분량·파일 형식·업무 유형별 기본 형식 (사용자가 채움)
    ├── formats/
    │   ├── idea-formats.md     아이디어 기획 형식 3종 — 옵션 비교 메모 / 아이디어 카드 / 결정 메모
    │   ├── research-formats.md 자료조사 형식 3종 — 근거표 / 1장 브리핑 노트 / 비교 매트릭스
    │   ├── data-formats.md     데이터 분석 형식 3종 — 분석 노트 / 지표 요약표 / 1장 경영 보고
    │   ├── plan-formats.md     기획안 작성 형식 4종 — 1장 품의 / 서술형 기획안 / 협업 요청 메일 / 실행 계획
    │   └── review-formats.md   결과물 검토 형식 3종 — 결함 로그 / 통과 기준 체크리스트 / 독자별 반려 사유 매트릭스
    ├── idea.md                 아이디어 기획 — 많이 내게 하지 말고, 다르게 내게 합니다
    ├── research.md             자료조사 — 찾은 것과 지어낸 것을 갈라내는 질문을 먼저 합니다(결과는 md 파일로 저장)
    ├── data.md                 데이터 분석 — 숫자를 읽게 하기 전에, 무엇을 세었는지부터 묻습니다
    ├── plan.md                 기획안 작성 — 쓰게 하기 전에, 읽는 사람이 무엇을 결정해야 하는지부터 줍니다
    ├── review.md               결과물 검토 — 잘 썼는지 묻지 말고, 어디서 틀리는지 묻습니다
    └── custom/
        └── _template.md        내 업무 유형을 추가하는 양식
```

세 층으로 나뉩니다. 업무 유형 노트(idea.md 등)는 질문 기법, formats/ 는 결과의 틀, format-profile.md 는 사용자 공통 기준입니다. 수강생이 고치는 파일은 format-profile.md 와 custom/ 두 곳뿐이고, 노트와 formats/ 는 강사 배포본 그대로 씁니다.

업무 유형 노트 다섯 개는 같은 구조입니다. 이 업무 유형으로 오는 신호, 먼저 확인하는 것, 첫 답이 왜 실패하는가, 질문 전략(기법 9~11개, 각각 근거 출처와 붙여 넣을 질문 문장), 실행 순서, 출력 형식(빈 틀과 채운 예시), 나쁜 질문 → 고친 질문 9~10개(적용 기법 표시), 점검 목록, 다음 단계, 출처.

## 호출 방법

Claude 대화창에서 다음과 같이 말합니다.

```
업무 질문 스킬로 작업해줘. (업무 설명 또는 파일 첨부)
```

줄여서 "질문 스킬로 작업해줘"라고 해도 같습니다. 실행하지 않고 질문만 받으려면 "업무 질문 스킬로 질문만 만들어줘"(안내 모드)라고 합니다. "질문을 어떻게 바꿔야 해", "뭘 먼저 물어야 해"도 안내 모드로 처리합니다. "조사해줘", "기획안 써줘"처럼 작업만 요청하면 이 스킬은 개입하지 않고 해당 작업 스킬이 맡습니다.

## 설치

- Claude 앱(claude.ai·데스크톱): Releases의 `question-router.skill` 파일을 내려받아 설정 → 기능(Capabilities) → 스킬(Skills)에서 업로드합니다. 등록 화면의 위치와 명칭은 앱 버전에 따라 다를 수 있으므로, 등록이 안 되면 Anthropic 도움말(support.claude.com)에서 "skills"를 검색합니다. Team·Enterprise 요금제는 관리자가 스킬 기능을 켜야 사용자가 등록할 수 있습니다.
- Claude Code: `question-router/` 폴더를 `~/.claude/skills/`에 복사합니다.

## 내 형식 기준 설정

references/format-profile.md 를 열어 종결어미, 표·산문 우선, 분량 상한, 파일 형식, 업무 유형별 기본 형식을 자기 값으로 바꿉니다. 비워 두면 기본값이 적용됩니다. 저장 후 스킬을 다시 올리면 모든 업무 유형 결과에 반영됩니다.

## 내 업무 유형 추가

references/custom/_template.md 를 복사해 새 이름(영문 소문자·하이픈)으로 저장하고 각 절을 채웁니다. 저장 후 스킬을 다시 올리면 오케스트레이터가 새 업무 유형을 다섯 기본 업무 유형과 같은 기준으로 판정에 포함합니다. 양식 안에 각 칸을 왜 채워야 하는지 적혀 있습니다.

## 강의 연결

이 스킬은 "Claude 활용으로 질문을 잘하는 방법" 10차시 과정의 실습 도구입니다. 4차시에서 등록해 첫 업무 유형을 쓰고, 4~8차시에서 업무 유형을 하나씩 다루며, 10차시에서 custom 업무 유형을 추가합니다. 차시 설계는 강의안에 있고, 이 스킬에는 각 차시에서 요청하는 기법과 예시만 들어 있습니다.

| 차시 | 업무 유형 |
|---|---|
| 4 | 아이디어 기획 (idea.md) |
| 5 | 자료조사 (research.md) |
| 6 | 데이터 분석 (data.md) |
| 7 | 기획안 작성 (plan.md) |
| 8 | 결과물 검토 (review.md) |
| 10 | 내 업무 유형 추가 (custom/_template.md) |

## 출처 등급

업무 유형 노트의 출처는 두 등급입니다. Anthropic 공식 문서와 학술 논문(arXiv·학회·저널)은 표시 없이 인용하고, 그 외 블로그·기업 자료는 "참고 수준"으로 표시했습니다. 출처가 없는 기법은 "실무 관행(출처 미확인)"으로 표시했습니다. 모든 출처는 2026-09-15에 확인했습니다. 2026-10-06 보강에서 기법 9건·예시 15건·형식 15종(업무 유형당 3종)과 형식 프로필을 추가했고, 새 기법 중 출처가 없는 것은 "실무 관행(출처 미확인)"으로 표시했습니다.
